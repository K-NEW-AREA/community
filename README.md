## 如何共创

除了提交新资源，也欢迎补说明、写读取脚本、清洗数据、复现与尝试新任务。每项贡献保留作者、整理者和验证者各自的记录。

流程：提交 Issue 或 PR → 核对与补充 → 审核收录 → 更新公开目录 → 使用反馈与再贡献。

本仓库首页就是当前公开目录；目录更新不代表独立网站已发布。收录、样例读取、独立复现分别记录。

## 平台分工与规则

- GitHub：公开目录、投稿、审核、讨论与变更记录。
- ModelScope 等：模型、数据集和大型实验文件。
- 飞书：规划中的内部跟进工作台，不要求参与者加入内部组织。

[阅读参与规则](GOVERNANCE.md)。请勿在公开投稿中填写令牌、私人联系方式或未经授权的材料。具体资源遵循其原始许可；本目录的介绍不能替代资源许可。
